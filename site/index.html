Turn YouTube videos into articles you can read instead of watch.

Recast follows the channels you choose. When one of them publishes, it transcribes the video on your own machine, has your AI provider write an article from it, and sends it to your inbox.

Install Recast View on GitHub

Four stages, from upload to inbox

Each video goes through these stages in order. Failed stages are retried automatically, and you can follow progress live, retry, cancel, or regenerate an article from the interface.

  1. Download

    yt-dlp

    Fetches the audio of each new video. Shorts, livestreams, and members-only videos are skipped.

  2. Transcription

    whisper.cpp

    Runs on your machine, on the CPU or on a GPU. The audio never leaves it.

  3. Article

    Copilot, Claude, or Codex

    Writes a summary and sections linked to the moment of the video they cover, in the language you pick.

  4. Delivery

    E-mail

    Sends the article to your inbox. Every article is also readable in the browser.

Yours to run, yours to shape

Follow channels
Every new video from the channels you follow becomes an article. You can also paste any video link by hand.
Write in any language
Articles use the language you pick in Settings, whatever the language of the video.
Shape the articles
Set a global prompt, and add instructions for each channel.
Bring your own AI provider
GitHub Copilot, Claude with your subscription or an API key, or OpenAI through Codex, with models from each provider’s catalog.
Track usage and cost
See the estimated cost per provider, model, and channel, and how much watching time became reading.
Run it on one machine
A small Bun server with a web interface and a SQLite database. The interface is in English or Brazilian Portuguese.

Install it on a machine that stays on

Recast runs on Linux or macOS. You need an account with one AI provider, and, for e-mail delivery, a Gmail app password or any SMTP server.

Ask a coding agent

Open Claude Code, Codex, or another agent on that machine and paste this. Review the commands it proposes before approving them.

Install and configure Recast (https://github.com/henriquearthur/recast) on this machine, following its README. Ask me which AI provider I want to use and whether I want e-mail delivery, and prefer Docker if it is available. When it is running, check that http://localhost:4280/api/health reports no problems.

Run it with Docker

The image includes every tool Recast needs. Set your provider credentials in .env before starting it.

git clone https://github.com/henriquearthur/recast.git
cd recast
cp deploy/recast.env.example .env
docker compose up -d

The first start downloads the Whisper model, about 1.6 GB. Prefer no Docker? Install without it.

Then open http://localhost:4280, pick a provider and model in Settings, and paste a video link or follow a channel.

Recast has no login. To read from your phone, keep it on your home network, a VPN, or a Tailscale tailnet. Never expose it directly to the internet.
